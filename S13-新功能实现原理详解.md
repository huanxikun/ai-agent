# S13 后台任务功能实现原理详解

## 一、新功能概览

S13 在现有 Agent Harness 中加入了**后台任务能力**，让较慢的只读研究任务可以异步执行，Agent 不必阻塞等待结果。

### 核心能力
- ✅ **异步执行** - 只读 Subagent 可在后台线程执行
- ✅ **结果注入** - 完成后通过 `task_notification` 自动注入结果
- ✅ **智能启发式** - 系统自动判断哪些任务应该后台执行
- ✅ **手动控制** - 支持显式指定 `run_in_background=true`
- ✅ **状态追踪** - 完整的后台任务状态管理和报告

## 三、实现细节

### 3.1 后台任务管理器 (BackgroundTaskManager)

**位置**：`src/main/java/com/example/agent/background/BackgroundTaskManager.java`

#### 核心数据结构

```java
public final class BackgroundTaskManager implements AutoCloseable {
    // 线程池（使用缓存的线程池，按需创建）
    private final ExecutorService executor;

    // 任务 ID 计数器
    private final AtomicInteger counter = new AtomicInteger();

    // 任务存储：ID → 任务对象
    private final ConcurrentMap<String, BackgroundTask> tasks;

    // 已完成任务 ID 队列
    private final ConcurrentLinkedQueue<String> completedIds;
}
```

#### 内部任务状态

```java
private final class BackgroundTask {
    private final String id;              // bg_0001, bg_0002, ...
    private final String toolName;        // 工具名称
    private final String summary;         // 任务摘要

    private volatile String status = "running";   // running, completed, failed
    private volatile String output;               // 任务输出
    private volatile Throwable error;             // 错误信息
}
```

#### 启动后台任务

```java
public BackgroundStart start(
        String toolName,
        String summary,
        Callable<String> job
) {
    // 1. 生成唯一 ID：bg_0001, bg_0002, ...
    String backgroundId = "bg_%04d".formatted(counter.incrementAndGet());

    // 2. 创建任务对象
    BackgroundTask task = new BackgroundTask(backgroundId, toolName, summary);
    tasks.put(backgroundId, task);

    // 3. 提交到线程池执行
    executor.submit(() -> {
        try {
            task.complete(job.call());           // 执行任务
        } catch (Exception exception) {
            task.fail(exception);                // 记录失败
        } finally {
            completedIds.offer(backgroundId);    // 标记完成
        }
    });

    // 4. 立即返回启动信息
    return new BackgroundStart(backgroundId, toolName, summary, "running");
}
```

#### 收集完成通知

```java
public List<BackgroundNotification> collectNotifications() {
    List<BackgroundNotification> notifications = new ArrayList<>();

    // 从队列中取出所有已完成的任务 ID
    String backgroundId;
    while ((backgroundId = completedIds.poll()) != null) {
        BackgroundTask task = tasks.remove(backgroundId);
        if (task == null) continue;

        // 将任务转换为通知对象
        notifications.add(task.toNotification());
    }

    return List.copyOf(notifications);
}
```

#### 任务状态摘要

```java
public BackgroundSummary summary() {
    int running = 0;
    int completed = 0;
    int failed = 0;

    for (BackgroundTask task : tasks.values()) {
        switch (task.status()) {
            case "running" -> running++;
            case "completed" -> completed++;
            case "failed" -> failed++;
        }
    }

    return new BackgroundSummary(tasks.size(), running, completed, failed);
}
```

### 3.2 AgentLoop 中的后台任务集成

**位置**：`src/main/java/com/example/agent/AgentLoop.java`

#### 决策逻辑：shouldRunInBackground()

```java
private boolean shouldRunInBackground(DeepSeekClient.ToolCall call) {
    // 条件1：后台任务管理器已启用
    if (backgroundTasks == null
            || !tools.supportsBackground(call.name())) {
        return false;
    }

    // 条件2：检查是否显式指定 run_in_background
    JsonNode arguments = call.arguments();
    if (arguments.has("run_in_background")) {
        return arguments.path("run_in_background").asBoolean(false);
    }

    // 条件3：启发式判断是否为慢速操作
    return isSlowOperation(call.name(), arguments);
}
```

#### 启发式判断：isSlowOperation()

```java
private boolean isSlowOperation(String toolName, JsonNode arguments) {
    // 只对 task 工具应用启发式规则
    if (!"task".equals(toolName)) return false;

    String description = arguments.path("description").asText("");
    String task = arguments.path("task").asText("");

    // 规则1：任务描述超过 240 字符
    if (task.length() >= 240) return true;

    // 规则2：包含"慢速操作"关键词
    String combined = (description + " " + task).toLowerCase();
    return combined.contains("整个项目")
            || combined.contains("全仓")
            || combined.contains("所有文件")
            || combined.contains("深入")
            || combined.contains("全面");
}
```

#### 后台执行逻辑

```java
for (DeepSeekClient.ToolCall call : response.toolCalls()) {
    toolCalls++;

    if (shouldRunInBackground(call)) {
        // ========== 后台执行 ==========
        BackgroundTaskManager.BackgroundStart started =
                backgroundTasks.start(
                        call.name(),
                        backgroundSummary(call),
                        () -> tools.execute(
                                call.name(),
                                call.arguments(),
                                toolContext
                        )
                );

        // 返回占位符结果
        output = json.writeValueAsString(Map.of(
                "status", "background_started",
                "message",
                "Background task %s started. Result will be delivered via task_notification."
                        .formatted(started.id()),
                "backgroundTask", started
        ));

        trace.add(event(
                "background",
                "后台任务启动 · " + call.name(),
                started.id() + " · " + started.summary()
        ));
    } else {
        // ========== 同步执行 ==========
        trace.add(event("hook", "Hook · PreToolUse", call.name()));
        try {
            output = tools.execute(call.name(), call.arguments(), toolContext);
            trace.add(event("hook", "Hook · PostToolUse", call.name() + " · success"));
        } catch (Exception exception) {
            trace.add(event("hook", "Hook · PostToolUse", call.name() + " · failed"));
            throw exception;
        }
    }
}
```

#### 通知注入：injectBackgroundNotifications()

```java
private void injectBackgroundNotifications(
        ArrayNode messages,
        ArrayNode memoryTranscript,
        List<Map<String, Object>> trace
) {
    if (backgroundTasks == null) return;

    // 收集所有已完成的后台任务
    List<BackgroundNotification> notifications =
            backgroundTasks.collectNotifications();
    if (notifications.isEmpty()) return;

    // 格式化通知内容
    String joined = notifications.stream()
            .map(this::formatBackgroundNotification)
            .reduce((left, right) -> left + "\n" + right)
            .orElse("");

    // 注入到消息列表
    messages.addObject()
            .put("role", "user")
            .put("content", joined);
    memoryTranscript.addObject()
            .put("role", "user")
            .put("content", joined);

    trace.add(event(
            "background",
            "后台任务通知注入",
            "完成数量=" + notifications.size()
    ));
}
```

#### 通知格式化

```java
private String formatBackgroundNotification(BackgroundNotification notification) {
    return "<task_notification>\n" +
           "后台任务 %s (%s) 已完成\n" +
           "状态：%s\n" +
           "摘要：%s\n" +
           "结果：%s\n" +
           "</task_notification>".formatted(
            notification.id(),
            notification.tool(),
            notification.status(),
            notification.summary(),
            notification.detail()
    );
}
```

#### ToolRegistry 中的支持检查

```java
public synchronized boolean supportsBackground(String name) {
    ToolDefinition tool = tools.get(name);
    return tool != null && tool.supportsBackground();
}

public synchronized List<String> backgroundToolNames() {
    return tools.values().stream()
            .filter(ToolDefinition::supportsBackground)
            .map(ToolDefinition::name)
            .toList();
}
```

## 四、关键技术要点

### 4.1 线程安全

**问题**：多线程访问后台任务状态

**解决方案**：
- 使用 `ConcurrentHashMap` 存储任务
- 使用 `ConcurrentLinkedQueue` 存储已完成 ID
- 使用 `volatile` 关键字保证状态可见性

```java
private final ConcurrentMap<String, BackgroundTask> tasks;
private final ConcurrentLinkedQueue<String> completedIds;

private volatile String status = "running";
private volatile String output;
```

### 4.2 任务 ID 生成

**问题**：需要唯一且易读的任务 ID

**解决方案**：
- 格式：`bg_0001`, `bg_0002`, ...
- 使用 `AtomicInteger` 保证线程安全
- 4 位数字格式化

```java
String backgroundId = "bg_%04d".formatted(counter.incrementAndGet());
```

### 4.3 占位符返回

**问题**：工具调用需要立即返回，但任务在后台执行

**解决方案**：
```java
{
    "status": "background_started",
    "message": "Background task bg_0001 started. Result will be delivered via task_notification.",
    "backgroundTask": {
        "id": "bg_0001",
        "tool": "task",
        "summary": "搜索代码库",
        "status": "running"
    }
}
```

### 4.4 通知注入时机

**问题**：何时注入后台任务完成通知？

**解决方案**：在两个时机注入
1. **用户消息处理前**（第 165 行）
   - 确保后续的模型调用能看到最新的后台任务结果

2. **每个工具循环处理后**（第 459 行）
   - 在同一轮次内完成的任务可以立即被看到

```java
// 时机1：处理用户消息前
injectBackgroundNotifications(messages, memoryTranscript, trace);
messages.addObject().put("role", "user").put("content", userMessage);

// 时机2：每个工具循环后
for (ToolCall call : response.toolCalls()) {
    // ... 处理工具调用 ...
}
injectBackgroundNotifications(messages, memoryTranscript, trace);
```

### 4.5 错误处理

**问题**：后台任务失败如何处理？

**解决方案**：
- 捕获所有异常，标记任务为 `failed`
- 通知中包含错误信息摘要
- 不会阻塞主 Agent 循环

```java
executor.submit(() -> {
    try {
        task.complete(job.call());
    } catch (Exception exception) {
        task.fail(exception);  // 标记失败
    } finally {
        completedIds.offer(backgroundId);  // 确保通知
    }
});
```

## 八、总结

### 8.1 核心实现机制

1. **BackgroundTaskManager** - 使用线程池异步执行任务
2. **shouldRunInBackground()** - 三层决策机制（支持检查 + 显式参数 + 启发式判断）
3. **injectBackgroundNotifications()** - 在下一轮循环注入完成结果
4. **ToolDefinition.supportsBackground** - 标记哪些工具支持后台执行

### 8.2 关键设计决策

| 决策 | 方案 | 原因 |
|------|------|------|
| 线程池 | CachedThreadPool | 按需创建，资源高效 |
| 任务存储 | ConcurrentHashMap | 线程安全，高性能 |
| 通知机制 | 消息注入 | 不修改模型，易于扩展 |
| 占位符返回 | background_started | 明确告知用户后台执行状态 |
| 启发式规则 | 关键词匹配 | 简单高效，避免复杂判断 |
